## 可依赖的接口面

- **平台 API** — 用户、工作区、模型、审计、设置（工作区外的 `/api/v1/*`）
- **工作区 API** — 摄入、账本、检索、图谱、本体、连接器（`/api/v1/workspaces/{workspace_id}/*`）
- **MCP** — 与 OpenAPI 同源的操作，按工作区 HTTP JSON-RPC 暴露

规范 HTTP 契约：[`/openapi/v1.json`](/openapi/v1.json)、[`/openapi/v1/platform.json`](/openapi/v1/platform.json)、[`/openapi/v1/workspaces.json`](/openapi/v1/workspaces.json)。
