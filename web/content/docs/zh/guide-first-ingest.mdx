**目标：** 工作区内有一份文档、处理任务完成、搜索能命中内容。

**前提：** 已完成 [快速开始](/docs/quickstart)，可登录并打开工作区。

## 步骤

1. 打开 **知识 → 资料源**。
2. 上传文本或 PDF（注意上传上限，见 [限制与错误](/docs/limits-and-errors)）。
3. 打开 **知识 → 处理**，等待任务 **completed**。
4. 在 **探索 → 搜索** 中查询应匹配的内容。
5. 可选：**图谱** / **实体** 查看投影更新。

## API 验证

使用会话或工作区令牌：`GET …/ingest/jobs`；搜索见 [工作区 OpenAPI](/openapi/v1/workspaces.json)。

## 故障排查

| 现象 | 检查 |
|------|------|
| 任务失败 | 处理页错误信息；文件大小与抽取上限 |
| 搜索为空 | 任务未完成；工作区或查询条件 |
| 图谱滞后 | 等待处理与投影完成 |
