## 本地开发

两个进程（见 [快速开始](/docs/quickstart)）：

1. **API** — 仓库根：`uv run basis`（默认 `:8090`）
2. **Web** — `web/`：`npm run dev`（默认 `:5173`，经 `BASIS_API_URL` 代理 API）

环境变量见 [配置参考](/docs/configuration)。

## Docker 生产（推荐）

单镜像内 **API + Hono Web**，**PostgreSQL** + `BASIS_DATA_DIR` 卷。

```bash
cd docker/production
cp .env.example .env
docker compose -f compose.yml up -d --build
```

浏览器访问 `http://localhost:8080`（或 `BASIS_HTTP_PORT`）。首个注册用户为平台管理员。

```text
浏览器 → :8080 (Hono)
           ├─ /           → SPA
           ├─ /console/*  → BFF
           └─ /api/*      → 127.0.0.1:8090 (FastAPI)
```

仅构建镜像：`docker build -f docker/production/Dockerfile -t basis:local .`

细节与 GHCR 标签：仓库 `docker/production/README.md`。

## 自定义反代

托管静态资源并转发 **`/api`**、**`/openapi`**、**WebSocket**；在 **管理 → 设置 → 登录** 配置对外 URL 以利 SSO。
