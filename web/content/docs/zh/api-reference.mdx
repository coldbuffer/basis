## 交互式浏览器

[打开 Swagger UI](/swagger) 从当前部署加载 spec。Try it out 从浏览器发请求；先登录可自动附带会话 token。

## Spec 变体

在浏览器工具栏切换完整、仅平台、仅工作区三份文档，或直接下载 JSON：

- [完整 OpenAPI](/openapi/v1.json)
- [平台 OpenAPI](/openapi/v1/platform.json)
- [工作区 OpenAPI](/openapi/v1/workspaces.json)

## MCP 工具

静态工作区 MCP 工具名与描述（由服务端元数据生成）：[MCP 工具索引](/docs/mcp-tools)。连接器 Manifest 衍生工具请对工作区端点调用 `tools/list` 获取。
