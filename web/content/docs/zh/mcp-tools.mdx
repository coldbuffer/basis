工作区 MCP `tools/list` 暴露的**静态核心工具**。**连接器 Manifest 工具**（`connector_\{service\}__…`）按提供方动态生成，不在此表。

参数 schema：对工作区 MCP 调用 `tools/list`，或使用 [Swagger](/swagger) / [工作区 OpenAPI](/openapi/v1/workspaces.json)。参见 [智能体工作流](/docs/agent-workflows)。

下表描述为服务端元数据（英文）。

### Workspace

| Tool | Access | Description |
| --- | --- | --- |
| `list_processing_jobs` | read | List document processing jobs (extract, chunk, project). |
| `reset_workspace` | write | Reset workspace data while keeping workspace id, members, and settings. preview=true returns counts, default_scopes, available_scopes, and export_pack_path. Otherwise pass confirmation=workspace name (exact) and optional scopes[] (knowledge, graph, connectors, reasoning, governance; default omits governance). async=true (default) enqueues jobs.kind=workspace_reset—poll via list_processing_jobs; async=false runs inline. Owner only. Do not use delete_node loops to clear a workspace. |

### Knowledge & ledger

| Tool | Access | Description |
| --- | --- | --- |
| `assign_entity_types` | write | Assign rdf:type to subjects directly (batch). Each item: subject_id (ledger entity or graph node id) + class_uri. Rebuilds graph projection when facts are created. Editor write. |
| `clear_entity_types` | write | Invalidate active rdf:type typed_facts for subjects (batch subject_ids). Rebuilds graph projection when any facts are cleared. Editor write. |
| `delete_document` | write | Hard-delete a document and its chunks, vectors, and ledger rows tied only to that document (same semantics as HTTP DELETE …/documents/\{document_id\}). document_id may be UUID or doc_id. Rebuilds graph projection. Editor write. |
| `delete_entity` | write | Hard-delete a ledger entity and its statements, typed/derived facts, and related rows (HTTP DELETE …/ledger/entities/\{entity_id\}). Irreversible; prefer invalidate_entities for soft temporal removal. Rebuilds graph projection. Editor write. |
| `entity_facts` | read | Open statements and inference-derived facts for a ledger entity id (derived_facts include proof-chain premises). |
| `get_chunk` | read | Fetch one chunk by id (from search_chunks). Use before cite or when extract_* needs full text. |
| `get_statement` | read | Resolve a ledger statement id to subject/object, predicate, and evidence (for tracing premises behind derived facts). |
| `invalidate_entities` | write | Soft-invalidate ledger entities (batch entity_ids): sets invalidated_at on the entity and on related statements, typed_facts, and derived_facts. Rebuilds graph projection. Prefer over delete_node for removing business entities from the canonical ledger. Editor write. |
| `list_entity_type_object_labels` | read | List rdf:type object labels from typed facts plus configured entity-type surface phrases (class mapping hints). |
| `list_mappings` | read | List statement-to-ontology mapping proposals (signature, target_uri, status). |
| `list_surface_phrases` | read | List distinct surface phrases seen in the ledger (for mapping signature suggestions). |
| `list_typed_facts` | read | List ontology-typed facts materialized from confirmed mappings (predicate URIs such as commercialContact, not raw document text). |
| `propose_mapping` | write | Create a statement-to-ontology mapping (proposed or confirmed), or direct class assignment when subject_id + target_kind class + target_uri are set (no signature). Confirmed requires editor. Same semantics as HTTP POST …/mappings for signature-based rows. |
| `search_chunks` | read | Search document chunks (RAG citations). Use chunk_id from results with propose_remember or optional chunk_id on graph/extract tools. See MCP resource semantica://guide/evidence. |
| `update_mapping_status` | write | Confirm, reject, or supersede a mapping (editor). Materializes typed facts on confirm. Same semantics as HTTP POST …/mappings/\{mapping_id\}/status. |

### Graph & decisions

| Tool | Access | Description |
| --- | --- | --- |
| `add_entity` | write | Add a node/entity to the workspace knowledge graph. Optional chunk_id and quote store basis_evidence in node metadata (graph write; not ledger propose_remember). |
| `add_relationship` | write | Add a directed relationship (edge) between two entities in the knowledge graph. Optional chunk_id and quote store basis_evidence on the edge metadata. |
| `delete_node` | write | Archive a projection graph node (status='archived' on the snapshot only; does not invalidate ledger entities or statements). node_count_active drops; node_count total unchanged. Full graph rebuild from ledger restores entities without the archive mark. Optional chunk_id, quote, and rationale attach evidence before archive. |
| `export_graph` | read | Export the current knowledge graph. Formats: turtle, ttl, nt, xml, json-ld, json, csv, graphml. |
| `extract_entities` | read | Extract named entities (people, places, organisations, concepts) from text using Semantica NER. Provide text or chunk_id (ledger chunk); optional quote. Response may include evidence when chunk_id is set. |
| `extract_relations` | read | Extract relations and (subject, predicate, object) triplets from text. Provide text or chunk_id; optional quote. Response may include evidence when chunk_id is set. |
| `find_precedents` | read | Find past decisions similar to a given scenario using hybrid similarity search. |
| `get_causal_chain` | read | Trace the causal chain upstream or downstream from a decision. |
| `get_graph_analytics` | read | Compute PageRank centrality and community detection over the knowledge graph. |
| `get_graph_summary` | read | Workspace and graph summary: ledger entity/document counts plus projection node_count (total), node_count_active, node_count_archived, edge_count, decision_count, graph_ready. |
| `paths` | read | Shortest path between two graph node ids. |
| `query_decisions` | read | Query recorded decisions by natural language, category, or get all recent decisions. |
| `query_graph` | read | Query the graph or ledger: mode node \| neighbors \| search (graph) \| entities (ledger). Neighbors/search omit projection nodes with status=archived unless include_archived=true. |
| `record_decision` | write | Record a decision into the workspace knowledge graph with full context, causal links, and metadata. Optional chunk_id and quote attach basis_evidence on the decision. |
| `update_node` | write | Update properties of an existing node (e.g. mark an action todo/doing/done with a note). Optional chunk_id, quote, and rationale are recorded in metadata and audit. |

| `list_ontology_drafts` | read | List saved ontology editor drafts for one ontology URI (newest-first order not guaranteed). |
| `list_ontology_proposals` | read | List ontology governance proposals (optional ontology_uri and state filters). |
| `list_ontology_registry` | read | List ontologies in the workspace hub registry (optional q and status filters). |
| `list_ontology_versions` | read | List published ontology versions for one ontology URI (from publish_ontology_proposal). |
| `list_vocabulary_alignments` | read | List recorded vocabulary alignments (URI equivalences and SKOS matches) in the ontology hub. Same semantics as HTTP GET …/ontology/alignments. |
| `publish_ontology_proposal` | write | Publish an approved proposal into the workspace graph (editor). Applies draft diff and records a version. Same semantics as HTTP POST …/ontology/proposals/\{id\}/publish. |
| `reject_ontology_proposal` | write | Reject a proposed ontology change (editor). Same semantics as HTTP POST …/ontology/proposals/\{id\}/reject. |
| `restore_ontology_version_draft` | write | Create an editor draft that restores the published head toward target_version (diff from latest published to target). Does not publish; submit via submit_ontology_proposal. Editor write. |
| `save_ontology_draft` | write | Save an ontology editor draft diff (editor). Persists hub sidecar; does not publish. diff keys: added_classes, added_properties, added_individuals, added_edges (source, target, type e.g. rdfs:subClassOf\|rdfs:domain\|rdfs:range), added_axioms (type subClassOf or rdfs:subClassOf; subject + object), modified_classes (label; or subClassOf/superclass/parent for hierarchy), modified_properties (label; or domain/range). Unknown keys are ignored. Use submit_ontology_proposal to open governance review. |
| `search_ontology_entities` | read | Search ontology hub entities by keyword (class, property, individual, concept, scheme). |
| `submit_ontology_proposal` | write | Submit a saved draft as a governance proposal (editor). Same flow as HTTP POST …/ontology/proposals. |
| `suggest_alignment_target_uri` | read | Match a surface label to class or property URIs using recorded vocabulary alignments (L1). Same semantics as HTTP GET …/ontology/alignments/suggest-target-uri. |
| `suggest_vocabulary_alignments` | read | Rank candidate URI alignments by label similarity across ontologies in the graph. Same semantics as HTTP POST …/ontology/suggest-alignments. |
| `toggle_ontology` | write | Toggle enabled flag for an ontology registry entry (editor). Disabled ontologies are omitted from explorer graph projection on rebuild. Same semantics as HTTP PATCH …/ontology/\{uri\}/toggle. |
| `upsert_vocabulary_alignment` | write | Create or update a vocabulary alignment between entity URIs (editor). Persists hub sidecar and projects an alignment edge into the graph. Same semantics as HTTP POST …/ontology/alignments. |
