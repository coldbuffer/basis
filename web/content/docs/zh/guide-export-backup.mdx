## 导出包

1. 打开工作区 **设置**。
2. 在 **图谱** 区域使用**导出**（图谱对比 / 集成 OpenAPI 亦有深链）。
3. 按留存策略保存到集群外。

导出面向 OpenAPI 文档中的投影包格式；生产环境仍需数据库级备份。

## 工作区重置（危险）

**重置工作区**按作用域清空账本/投影等，**保留**工作区 id、成员与设置；不同于删除工作区。

1. **设置 → 危险操作 → 重置工作区**（owner/admin）。
2. 查看预览计数（`GET …/reset`）。
3. 勾选 **scopes**，以工作区**名称**确认。
4. 默认**异步**作业 — 轮询 `ingest/jobs`。

全库清理请用重置 API/MCP，勿用 `delete_node` 刷屏。
