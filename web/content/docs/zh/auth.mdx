## 控制台用户

通过 `/api/v1/auth/*` 注册登录；会话使用 Cookie，必要时 SPA 使用 Bearer 调用 API。

## 访问令牌

在控制台创建令牌供脚本与智能体使用；工作区令牌将 MCP 与工作区 OpenAPI 限定在单个工作区（API 参数名为 `workspace_id`）。

## 角色

平台管理员管理用户与设置；工作区成员按角色（查看、编辑等）在 `/api/v1/workspaces/{workspace_id}/*` 路由上鉴权。

## 企业 SSO（组织）

组织可使用 OIDC 或 SAML 登录。SSO **仅影响控制台登录**；工作区 API 令牌与 MCP Bearer 不变。

分步配置：[指南：企业 SSO](/docs/guide-enterprise-sso)。

发现接口：`GET /api/v1/auth/org-sso-options`、`GET /api/v1/auth/org-sso-hint?email=…`；浏览器流程：`/api/v1/auth/oidc/*`、`/api/v1/auth/saml/*`。
