**目标：** 组织用户通过 IdP 登录；API 令牌与 MCP 不变。

## 前提

- 平台**管理员**
- **管理 → 设置 → 登录** 中对外站点 URL 正确（回调据此生成）

## 配置 IdP

1. **管理 → 设置 → 组织 SSO**。
2. 选择组织。
3. 添加 **OIDC**、**SAML** 或 **CAS**。CAS 填服务器根地址和邮箱属性名。登录路径、校验路径默认是 `/login` 和 `/serviceValidate`，可以改成 IdP 实际路径。
4. 保存。OIDC/SAML 把回调 URL 填入 IdP；CAS 把页面上的 service 地址原样登记为允许的 service。

## 登录行为

- `GET /api/v1/auth/org-sso-options`
- `GET /api/v1/auth/org-sso-hint?email=…`
- OIDC：`/api/v1/auth/oidc/{slug}/start`
- SAML：`/api/v1/auth/saml/*`
- CAS：`/api/v1/auth/cas/{slug}/start`，回调 `/api/v1/auth/cas/callback` 按配置的校验路径核验票据（默认 `/serviceValidate`）

每种登录方式各自有开关：密码和邮箱链接在访问设置里，OIDC、SAML、CAS 在组织卡片上。打开一种不会关掉另一种。

## 运维检查

| 项 | 说明 |
|----|------|
| 时间同步 | API 与 IdP 时钟 |
| HTTPS | 生产环境 TLS |
| 登出 | 按需配置 SAML SLO |
| 应急账号 | 按组织策略保留本地管理员 |
