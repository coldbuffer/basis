改变账本规范态的**生产写入**通常经**审核**。检索、图谱与 MCP 读工具不能替代写入门控。

## 审核队列

**治理 → 审核**展示待办：陈述导入、合并、映射确认、智能体 **记忆** 提案、连接器**写回**、冲突处理等。

典型流程：创建审核项 → 审阅 diff 与来源 → **批准**（SHACL、冲突扫描）或 **拒绝**。

智能体 **remember** 与人工提案共用同一队列。

## 冲突与规则

批准部分陈述会触发**冲突检测**；审阅人可指定保留陈述。

**推理规则**可派生事实；试跑在 **分析** 中，生产写入仍走审核。

## 决策与活动日志

**活动日志**与 decisions API 提供**决策链**叙事；`?decision=` 深链可聚焦单项。

## 告警

工作区**告警**（账户菜单）含治理类事件（如影响门控触发）。集成页 **OpenAPI** 标签说明告警 REST 端点。

## 连接器写回

批准的实体变更可进入 BOCP **outbox**；审核 UI 展示朝向上游的 diff。
