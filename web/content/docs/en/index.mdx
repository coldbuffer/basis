## Surfaces you can rely on

- **Platform API** — users, workspaces, models, audit, settings (`/api/v1/*` outside workspace scope)
- **Workspace API** — ingest, ledger, search, graph, ontology, connectors (`/api/v1/workspaces/{workspace_id}/*`)
- **MCP** — same operations as OpenAPI, scoped per workspace over HTTP JSON-RPC

Normative HTTP contracts: [`/openapi/v1.json`](/openapi/v1.json), [`/openapi/v1/platform.json`](/openapi/v1/platform.json), [`/openapi/v1/workspaces.json`](/openapi/v1/workspaces.json).
