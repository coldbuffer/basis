## Alignment with OpenAPI

MCP tools map to the same operations as OpenAPI v1. Prefer MCP when the client already speaks the protocol; use REST for generic HTTP integrations.

## Setup outline

Open **Integration** under **System** in the workspace sidebar (`/workspaces/{workspace_id}/integration`). The page has three tabs — **MCP** (default), **OpenAPI**, and **Access tokens**:

1. On **Access tokens**, create a workspace token (owners/admins).
2. On **MCP**, copy the HTTP MCP URL and optional Cursor config snippet.
3. In your agent host, send `Authorization: Bearer <token>` on MCP (and REST) calls.

Cursor-specific steps: [Guide: MCP in Cursor](/docs/guide-mcp-cursor). Typical read/write loops: [Agent workflows](/docs/agent-workflows).
