## Console users

Register and sign in via `/api/v1/auth/*`. Sessions use cookies; the SPA stores a Bearer token for API calls when needed.

## Access tokens

Create tokens in the console for scripts and agents. Workspace tokens scope MCP and workspace OpenAPI paths to a single workspace (`workspace_id` in the API).

## Roles

Platform admins manage users and settings. Workspace members have roles (viewer, editor, …) enforced on each `/api/v1/workspaces/{workspace_id}/*` route.

## Enterprise SSO (organizations)

Organizations can sign in through OIDC or SAML instead of (or alongside) local passwords. SSO affects **console login only** — workspace API tokens and MCP Bearer credentials are unchanged.

Step-by-step IdP setup: [Guide: enterprise SSO](/docs/guide-enterprise-sso).

Discovery endpoints: `GET /api/v1/auth/org-sso-options`, `GET /api/v1/auth/org-sso-hint?email=…`; browser flows under `/api/v1/auth/oidc/*` and `/api/v1/auth/saml/*`.
